# Spec Delta

## ADDED Requirements

### Requirement: Имя инстанса и группы определяется окружением развёртывания

Имя инстанса SHALL определяться окружением развёртывания, а не статическим перечнем стенда: явно
заданное имя инстанса SHALL иметь приоритет, при его отсутствии имя SHALL браться из имени пода, а
при его отсутствии — из имени хоста. Имя группы SHALL браться из явной конфигурации окружения, а при
её отсутствии — из имени namespace. Сегменты пути по-прежнему обязаны быть непустыми: инстанс, у
которого ни один источник не дал имени, SHALL прекратить запуск с сообщением о проблемном сегменте.

Имя сессии пула (имя приложения, под которым пул виден в базе данных) SHALL равняться имени
инстанса: пул процесса SHALL подключаться к базе под именем, совпадающим с именем узла регистрации.

#### Scenario: Явное имя инстанса имеет приоритет

- **WHEN** имя инстанса задано явно, а имя пода и имя хоста также доступны
- **THEN** узел регистрации и имя сессии пула используют явно заданное имя

#### Scenario: Имя из имени пода

- **WHEN** явное имя инстанса не задано, а имя пода доступно
- **THEN** узел регистрации и имя сессии пула используют имя пода

#### Scenario: Имя из имени хоста

- **WHEN** ни явного имени инстанса, ни имени пода нет, а имя хоста доступно
- **THEN** узел регистрации и имя сессии пула используют имя хоста

#### Scenario: Группа из namespace

- **WHEN** явное имя группы не задано, а имя namespace доступно
- **THEN** группа пути конфигурации равна имени namespace

#### Scenario: Имени нет ни из одного источника

- **WHEN** имя инстанса не задано явно и не получено из окружения развёртывания
- **THEN** запуск прекращается с сообщением, называющим отсутствующий сегмент
