# Spec Delta

## MODIFIED Requirements

### Requirement: Числовые параметры ограничены допустимыми диапазонами

Каждый числовой параметр конфигурации SHALL иметь допустимый диапазон, отклонение от которого
приводит к отказу всей конфигурации. Локальное значение размера пула SHALL принимать 0 (пул
отсутствует) либо значение из диапазона допустимых размеров; максимальный размер SHALL быть
ограничен сверху. Размер пула, полученный из etcd, SHALL быть не меньше единицы: хранилище
управляется провижером, и 0 из etcd SHALL отклоняться вместе со всей конфигурацией. Параметры,
допускающие отключение, SHALL принимать значение отключения либо попадать в диапазон. Таймаут
ожидания соединения SHALL иметь минимальное значение, исключающее возврат соединения немедленно
после его запроса.

#### Scenario: Значение ниже минимума

- **WHEN** задан таймаут ожидания соединения меньше минимально допустимого
- **THEN** конфигурация отклонена, пул остаётся на прежних значениях, причина сообщается

#### Scenario: Размер пула вне диапазона

- **WHEN** в etcd задан размер пула ноль или больше верхней границы
- **THEN** конфигурация отклонена целиком, пул остаётся на последних рабочих значениях

#### Scenario: Локальный размер пула равен нулю

- **WHEN** локальное значение размера пула равно 0, а в etcd размер не задан
- **THEN** конфигурация принимается с размером пула 0, и пул отсутствует

### Requirement: Минимум свободных соединений по умолчанию следует за размером пула

Если значение минимального числа свободных соединений не задано, оно SHALL вычисляться равным
размеру пула, чтобы уменьшение пула не нарушало инвариант «минимум не превышает максимум».
Явно заданное значение SHALL всегда использоваться как есть.

#### Scenario: Минимум не задан при уменьшении пула

- **WHEN** минимальное число свободных соединений не задано, а размер пула уменьшается
- **THEN** минимум становится равен новому размеру, и уменьшение применяется успешно

#### Scenario: Минимум при нулевом размере

- **WHEN** размер пула равен 0, а минимальное число свободных соединений не задано
- **THEN** минимум становится равным 0 вместе с размером пула
