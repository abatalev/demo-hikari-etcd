## REMOVED Requirements

### Requirement: Смена целевого соединения пересоздаёт пул

Требование снимается: целевая часть конфигурации (адрес базы, учётные данные, имя пула) больше
не приходит из хранилища конфигурации и задаётся только локально, поэтому смена цели на
работающем пуле через конфигурацию недостижима. Пересоздание пула остаётся возможным по другой
причине — выходом из нулевого целевого размера, и его требование сохраняется.

Прежние сценарии «Смена адреса базы» и «Повторная запись того же значения» уходят вместе с
требованием: оба описывали смену цели из конфигурации.
