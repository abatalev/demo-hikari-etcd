# Spec Delta

## MODIFIED Requirements

### Requirement: Конфигурация из etcd имеет приоритет над локальными значениями

Значение, заданное в etcd, SHALL переопределять соответствующее локальное значение по умолчанию.
Переопределяться SHALL только размер пула и минимум свободных соединений; ключ, отсутствующий в
etcd, SHALL приводить к использованию локального значения по умолчанию для этого ключа. Локального
значения размера пула SHALL NOT существовать: размер приходит только из хранилища конфигурации, и
при отсутствии ключа размера пул SHALL быть закрыт (целевой ноль), а не получать локальный дефолт.
Отсутствующим ключом SHALL считаться в том числе любой параметр вне перечня распознаваемых.

#### Scenario: Ключ задан в etcd

- **WHEN** в etcd задано значение размера пула
- **THEN** применено значение из etcd, а не локальное

#### Scenario: Ключ отсутствует

- **WHEN** ключ размера отсутствует в etcd
- **THEN** пул закрыт (целевой ноль): локального значения размера нет, а оставшиеся локальные
  значения (таймауты, цель соединения) применяются как обычно

### Requirement: Числовые параметры ограничены допустимыми диапазонами

Каждый числовой параметр конфигурации SHALL иметь допустимый диапазон, отклонение от которого
приводит к отказу всей конфигурации. Размер пула SHALL задаваться только из хранилища
конфигурации: локального значения размера SHALL NOT существовать, и размер, полученный из
хранилища, SHALL быть ограничен сверху. Размер пула, полученный из etcd, SHALL быть не меньше
единицы: хранилище управляется провижером, и 0 из etcd SHALL отклоняться вместе со всей
конфигурацией. Параметры, допускающие отключение, SHALL принимать значение отключения либо
попадать в диапазон. Таймаут ожидания соединения SHALL иметь минимальное значение, исключающее
возврат соединения немедленно после его запроса, и это ограничение SHALL применяться к локальному
значению, поскольку из хранилища конфигурации таймауты не принимаются.

#### Scenario: Значение ниже минимума

- **WHEN** задан таймаут ожидания соединения меньше минимально допустимого
- **THEN** конфигурация отклонена, пул остаётся на прежних значениях, причина сообщается

#### Scenario: Размер пула вне диапазона

- **WHEN** в etcd задан размер пула ноль или больше верхней границы
- **THEN** конфигурация отклонена целиком, пул остаётся на последних рабочих значениях

#### Scenario: Локальный размер пула равен нулю

- **WHEN** конфигурация применяется, а ключ размера в etcd отсутствует
- **THEN** пул отсутствует (целевой ноль): локального значения размера не существует, и ноль не
  выводится из локального дефолта

### Requirement: Нечитаемое значение игнорируется только для своего ключа

Если значение ключа не является числом, сервис SHALL игнорировать только этот ключ — его значение
SHALL NOT применяться — и применить остальные ключи конфигурации как обычно. Для размера пула
локального значения по умолчанию SHALL NOT существовать, поэтому битый размер SHALL оставаться
неприменённым, а не заменяться дефолтом. Причина SHALL быть видна в наблюдаемом состоянии.

#### Scenario: Одно битое значение среди корректных

- **WHEN** один ключ содержит нечисловое значение, а остальные корректны
- **THEN** остальные ключи применены, битый ключ не применён (локального значения для него нет),
  причина указана в наблюдаемом состоянии
