# Spec Delta

## MODIFIED Requirements

### Requirement: Экземпляр принимает трафик только после получения конфигурации

Экземпляр SHALL NOT принимать запросы обслуживания, пока не получил конфигурацию из хранилища.
Получение конфигурации SHALL открывать трафик. Полученная, но отклонённая конфигурация SHALL
NOT удерживать трафик: значение из хранилища получено, экземпляр становится готовым, а пул
работает на последних рабочих значениях. Снятие конфигурации (исчезновение всех распознанных
ключей по реальным событиям хранилища — например, провижер удалил ключи инстанса, потерявшего
долю бюджета) SHALL закрывать трафик до тех пор, пока конфигурация не появится снова.
Недоступность хранилища сама по себе SHALL NOT закрывать трафик: события в этом случае не
приходят, откат происходит только по фактическим изменениям ключей.

#### Scenario: Хранилище недоступно на старте

- **WHEN** экземпляр стартует при недоступном хранилище
- **THEN** запросы обслуживания отклоняются, процесс остаётся запущенным

#### Scenario: Конфигурация получена

- **WHEN** хранилище доступно и снимок содержит ключи конфигурации
- **THEN** экземпляр принимает запросы обслуживания

#### Scenario: Полученная конфигурация отклонена при проверке

- **WHEN** снимок содержит ключи, а полученная конфигурация не прошла проверку
- **THEN** экземпляр принимает запросы, пул работает на последних рабочих значениях, причина
  доступна для наблюдения

#### Scenario: Конфигурация снята

- **WHEN** хранилище доступно, и распознанные ключи конфигурации удаляются все (инстанс потерял
  долю бюджета)
- **THEN** экземпляр перестаёт принимать запросы, готовность закрыта, наблюдение и живость
  продолжают работать

#### Scenario: Конфигурация возвращена

- **WHEN** после снятия конфигурации распознанные ключи снова появляются (инстанс снова получил
  долю бюджета)
- **THEN** экземпляр снова принимает запросы без перезапуска

#### Scenario: Хранилище перестало отвечать после применения

- **WHEN** хранилище становится недоступным после того, как конфигурация была применена
- **THEN** запросы продолжают обслуживаться на последней применённой конфигурации, готовность
  остаётся положительной
