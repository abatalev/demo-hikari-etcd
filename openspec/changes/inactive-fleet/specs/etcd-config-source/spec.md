# Spec Delta

## MODIFIED Requirements

### Requirement: Пустой префикс не остаётся незамеченным

Снимок префикса, не содержащий ни одного ключа, SHALL сопровождаться предупреждением, из которого
понятен путь. Состояние источника SHALL показывать, что конфигурация по этому пути не получена.
Пока конфигурация не получена, служба SHALL работать на локальных значениях по умолчанию: при
локальном размере пула 0 пула SHALL NOT существовать, и запросы обслуживания SHALL отклоняться.

#### Scenario: В пути нет ни одного ключа

- **WHEN** снимок пути конфигурации не содержит ключей
- **THEN** в журнал выводится предупреждение с указанием пути, и из состояния источника видно,
  что конфигурация не получена

#### Scenario: Пустой путь и локальный ноль

- **WHEN** снимок пути пуст, а локальный размер пула по умолчанию равен 0
- **THEN** пул не создан, запросы обслуживания отклоняются, процесс остаётся запущенным

## ADDED Requirements

### Requirement: Нулевой размер пула из etcd отклоняется

Значение `maximumPoolSize`, равное нулю, полученное из etcd, SHALL отклоняться вместе со всей
конфигурацией, даже если 0 входит в допустимый диапазон локальных значений. Причина SHALL быть
видна в наблюдаемом состоянии. Отклонение SHALL NOT закрывать трафик: экземпляр остаётся готовым,
а пул работает на последних рабочих значениях.

#### Scenario: Ноль записан в etcd

- **WHEN** в etcd записано значение `maximumPoolSize`, равное 0
- **THEN** конфигурация отклонена целиком, причина видна в наблюдаемом состоянии, трафик не
  закрывается, пул остаётся на последних рабочих значениях

#### Scenario: Возврат к рабочему размеру

- **WHEN** после отклонения нуля в etcd записано допустимое значение размера пула
- **THEN** конфигурация применяется, и пул приводится к новому размеру
